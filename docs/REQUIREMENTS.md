# Requisitos confirmados — CPAD

Fonte: `CPAD - Global Solution 2026.2 - Territory Predictive Insights(1).pdf`, fornecido pelo aluno. Disciplina: **Cross-Platform Application Development**. Este repositório fica em preparação; implementação após POO e DSA, conforme prioridade do aluno.

## Produto

- Aplicativo mobile funcional em **Flutter** para inteligência territorial, consumindo dados públicos, sintéticos ou autorizados.
- Alertas derivados de regras ou previsões, com evidência, nível de confiança, limitações e decisão final humana.
- Navegação por múltiplas telas com rotas nomeadas e passagem de parâmetros; checklist pede **ao menos cinco telas**.
- **Três dashboards distintos** com gráficos, indicadores, histórico e tendência.
- Estado local/global separado e compartilhado entre pelo menos duas telas; carregamento, erro e lista vazia.
- Consumo de API ou serviço externo real ou simulado; persistência local; utilidade offline.
- Formulário funcional com validação; tema e componentes reutilizáveis; responsividade.
- Contraste, fonte ampliada e leitor de tela; anonimização, consentimento e indicador de benefício social.
- Vídeo de demonstração de **até três minutos**.
